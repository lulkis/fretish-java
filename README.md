# JFret

An implementation of a FRET to LTL translator written in Java.

FRET Poject: https://github.com/NASA-SW-VnV/fret

___

This project just supports FRETish translation into ptLTL. 

#### Usage
Just give the FRETish Formula as an argument to the programm.
```
./gradlew run --args="FROMULA"
```
